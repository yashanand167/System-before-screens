# Thinking Beyond Canvas 📖
> **AI for Product Designers** — A practical handbook on designing products in the age of intelligence systems.

![Thinking Beyond Canvas](public/CoverUI.png)

This repository contains the interactive landing page and web interface for the handbook **"Thinking Beyond Canvas"**. It explores how AI is transforming the product design process, the skills we need to build, and the mindsets that will shape the future of human-AI collaboration.

---

## 🌟 Key Highlights

- **AI as a Cognitive Partner**: Shifting from using AI for quick shortcuts to using it as a collaborative sparring partner to stress-test flows, logic, and assumptions.
- **The Prompt is the New Sketch**: Treating language as the new primary interface of design, where precision of vocabulary replaces precision of pixels in early phases.
- **Probabilistic UI**: Designing fluid layouts that adapt dynamically based on AI confidence scores rather than static, deterministic states.
- **Curation over Creation**: Cultivating taste, critical restraint, and editorial judgment as the ultimate designer superpowers when generation costs drop to zero.
- **Human-in-the-Loop**: Building systems at the intersection of human intuition and algorithmic scale with steerable controls.

---

## 📚 Handbook Index

1. **Thinking** — Reframing the designer-AI partnership.
2. **Research** — Leveraging intelligent synthesis without losing user empathy.
3. **Systems** — Designing adaptive, non-deterministic pattern libraries.
4. **Workflows** — Integrating AI copilots into day-to-day design pipelines.
5. **Prompting & Judgement** — Cultivating taste as the core quality bar.
6. **Future** — The emerging landscape of design before and beyond screens.

## 🚀 Getting Started

To run the interactive landing page locally:

### 1. Clone the repository
```bash
git clone git@github.com:yashanand167/System-before-screens.git
cd System-before-screens
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the interactive interface.
